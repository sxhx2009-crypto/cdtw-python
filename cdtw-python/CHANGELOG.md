# Changelog

## 0.2.1 — 2026-08-20

- 매개변수 격자에서 곡선 꼭짓점을 앵커로 보존하도록 수정. 전체 호 길이 대비
  `32*eps`보다 짧은 선분이 병합돼 사라지면서 발생하던 두 가지 문제를 함께
  해결한다.
  - `RuntimeError: a curve vertex is missing from the parameter grid` 크래시.
    재현: `cdtw_distance([0.0, 1e-9, 1e6], [0.0, 1e6])`
  - 총 호 길이가 약 `1e-13` 이하인 곡선에서 모든 표본이 한 좌표로 무너져
    **조용히 `0.0`(또는 `inf`)을 반환**하던 오답. 재현:
    `cdtw_distance([0.0, 1e-13], [-1.0, -1.0])`
- `_break_indices`의 허용오차를 국소 좌표가 아니라 `_unique_sorted`와 같은
  전역 호 길이 스케일로 측정하도록 통일. 두 허용오차가 어긋나 있던 것이
  위 크래시의 직접 원인이었다.
- 두 곡선의 길이가 거의 같아 좌표계를 공유할 때, 공유 좌표계를 곡선별로
  잘라내어 격자가 항상 순증가하고 끝점이 정확하도록 보장.
- 공선점 재표본화 편차, 극단적 크기비, 미소 곡선에 대한 회귀 테스트 4종 추가
  (14개 → 18개).
- README에 공선점 재표본화 비불변성과 삼각부등식 미성립을 명시.

## 0.2.0 — 2026-08-19

- 셀 내부 닫힌형 비용을 사용하는 경계표본 CDTW 구현
- 시작·끝 대칭 격자로 공동 역순 불변성 회귀 수정
- `cdtw_adaptive`에 기본 3단계 안정화 창 적용
- 기본 512 MiB 보수적 메모리 가드 추가
- 14개 단위 테스트와 재현 가능한 전문 검증 자료 추가
- GitHub Actions 및 `pyproject.toml` 기반 설치·빌드 지원

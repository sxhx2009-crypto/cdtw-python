# CDTW Python 구현 전문 검증 보고서

- 검증일: 2026-08-19
- 고정 난수 시드: `20260819`
- 환경: Python 3.12.13, NumPy 2.3.5, Linux x86-64
- 최종 상태: **PASS**
- 총 검증 시나리오: **2,381개**(스트레스 시험 1건 포함)
- 총 명시적 검증 조건: **7,772개**

## 1. 검증 목적과 판정 범위

이 검증은 다음 두 질문을 구분해서 다룬다.

1. 구현된 수치 알고리즘이 자체 정의대로 정확하고 일관되게 작동하는가?
2. 그 결과가 논문의 연속 CDTW 최적값과 완전히 같은가?

1번에 대해서는 해석해·독립 적분·변환 성질·별도 알고리즘과의 비교를 통해
강한 근거를 확보했다. 그러나 이 코드는 셀 경계 통과 위치를 표본화하는
**수렴형 근사 알고리즘**이므로, 2번의 완전한 동일성을 증명하지는 않는다.
논문의 정확한 조각별 이차 경계함수 전파 알고리즘을 구현한 것은 아니다.

## 3. 반환 경로에 대한 인증형 검사

거리값만 비교하지 않고, 무작위 곡선 300쌍에서 반환된 정합 경로 자체를 별도
코드로 다시 검사했다.

- 모든 경로가 두 매개변수 축에서 단조 비감소했다.
- 모든 경로가 정확히 `(0,0)`에서 시작해 두 곡선의 전체 호 길이에서 끝났다.
- 경로를 원래 곡선의 모든 꼭짓점에서 다시 분할한 뒤 독립적으로 선적분했다.
- 재적분 비용과 보고된 비용의 최대 상대오차는 `1.50e-15`였다.

따라서 계산된 값이 실제로 반환된 하나의 실행 가능한 단조 연속 정합 경로의
비용이라는 점은 수치적으로 확인됐다.

## 4. 독립 알고리즘과의 차등검사

검증 스위트에는 본 구현의 셀 내부 최적비용 공식을 사용하지 않는 별도
격자-DP를 작성했다. 이 비교 알고리즘은 수평·수직·대각선 **직선 간선**만
허용하므로 그 결과는 실행 가능한 경로의 상계다.

- 120건 모두 본 구현의 결과가 독립 상계보다 작거나 같았다.
- 최대 절대 상계 위반은 `2.84e-14`로 부동소수점 반올림 수준이었다.
- 셀 내부 최적화를 사용함으로써 직선 격자보다 최대 `21.68%` 낮은 실행 가능한
  비용을 찾은 사례가 있었다.

## 6. 검증 과정에서 발견하고 수정한 문제

초기 전문 검사에서는 두 곡선을 동시에 역순으로 뒤집었을 때 일부 유한격자
결과가 달라졌다. 300개 예비 사례에서 최대 상대 차이는 약 `1.41%`였다.

원인은 짧은 곡선의 매개변수 격자가 시작점 기준으로만 배치되어, 곡선을 뒤집으면
허용되는 셀 경계 통과점 집합이 달라지는 것이었다. 각 곡선별로 모든 표본의
끝점 기준 반사 위치도 함께 추가하도록 수정했다. 수정 후 500건에서 동시 역순
최대 상대오차는 `1.04e-15`로 감소했다. 이 사례는 단순 단위 테스트보다
변환 기반 검사가 필요한 이유를 보여준다.

## 7. 후속 검토에서 발견한 안전성 문제와 수정

### 6.1 `cdtw_adaptive` 평탄 구간 조기 종료

기존 판정은 마지막 두 해상도 값이 허용오차 안이면 바로 `converged=True`로
종료했다. 그러나 다음 입력에서는 64와 128의 값이 정확히 같고 256에서 다시
감소했다.

| 격자 | 거리 |
|---:|---:|
| 64 | `3.560812020508` |
| 128 | `3.560812020508` |
| 256 | `3.560121528870` |

수정본은 기본적으로 마지막 **3번의 연속 해상도 변화**가 각각 허용오차를
만족해야 종료한다. `estimated_error`는 이 최근 창에서 관측된 절대 변화량의
최댓값이다. 회귀 시험에서 수정본은 128에서 멈추지 않고 256까지 진행했으며,
최대 격자에 도달한 시점의 `converged`를 올바르게 `False`로 보고했다.

이 수정은 조기 종료 가능성을 낮추는 경험적 안정화 정책이다. 유한 개 변화량만으로
연속 최적값에 대한 엄밀한 오차 상한을 얻을 수는 없으므로 `converged`와
`estimated_error`는 여전히 인증값이 아니다.

별도 시드 `20260820`으로 길이 6인 무작위 곡선 30쌍을 검사했다. 수정된
adaptive 결과를 요청 가능한 최종 `grid_size=1024` 결과와 비교했을 때 14건은
512에서 먼저 안정화됐고, 전체 최대 상대 차이는 `1.13e-5`였다. 설정한
`rtol=1e-4`, `atol=1e-8` 기준 위반은 0건이었다. 이는 해당 표본과 최종 격자에
대한 회귀 결과이지 연속 최적값에 대한 증명은 아니다.

### 6.2 메모리 가드

수정본은 실제 매개변수 격자와 원래 셀별 경계 표본 수를 이용해 전역 DP 배열,
경로 선행자 배열 및 가장 큰 셀의 임시행렬을 보수적으로 추정한다. 기본 한도는
`memory_limit_mib=512.0`이다.

- 회귀 입력, `grid_size=8192`의 실제 격자: `8201 x 12548`
- 경로 미복원 보수적 추정: 약 `6494.17 MiB`
- 경로 복원 보수적 추정: 약 `9634.62 MiB`
- 두 모드 모두 대형 DP 배열 할당 전에 `MemoryError` 발생 확인

이 수치는 실제 사용량 측정값이 아니라 안전한 사전 차단을 위한 보수적 추정치다.
한도는 시스템 메모리를 확인한 경우에만 올리거나 `None`으로 해제해야 한다.

### 6.3 0길이 상수 곡선 경고

배열 인덱스는 시간 좌표로 보존되지 않는다. 두 입력이 모두 상수 곡선이면 값이
서로 달라도 두 호 길이가 모두 0이므로 논문 정의상 적분값은 0이다. 이 동작을
README와 모듈 문서 상단에 명시했다.

## 8. 재표본화 수렴 진단

원래 곡선의 각 선분 중점을 추가해 기하학적으로 같은 곡선을 만든 뒤 결과 차이를
측정했다. 연속 CDTW의 참값은 재표본화에 불변이지만, 유한 경계 표본 근사는
새 셀 경계 때문에 완전히 같지 않을 수 있다.

| 격자 | 최대 상대 차이 | 중앙값 |
|---:|---:|---:|
| 32 | `0.7852%` | `2.81e-16` |
| 128 | `0.05345%` | `2.57e-16` |

120건 중 119건에서 격자를 세분했을 때 차이가 감소하거나 유지됐다. 이는
예상한 수렴 거동과 일치하지만, `estimated_error`가 엄밀한 오차 상한이라는 뜻은
아니다. 재표본화가 많은 데이터에서는 `cdtw_adaptive`의 전체 해상도 이력을
함께 기록하되 `converged`를 인증된 오차 보장으로 해석하지 않아야 한다.

## 9. 스트레스 시험

각각 120개 꼭짓점을 가진 무작위 곡선, 요청 격자 크기 512에서 측정했다.

- 실제 매개변수 격자: `1170 x 749`
- 반환 경로 점: 469개
- 실행시간: 약 4.94초
- `tracemalloc` 최대 추적 메모리: 약 33.56 MiB

수치는 현재 검증 환경의 참고값이며 다른 CPU·Python·NumPy 버전에서는 달라질
수 있다. 또한 `tracemalloc`은 운영체제 수준의 전체 프로세스 메모리 측정값과
동일하지 않다.

## 10. 코드 실행 범위

Python 표준 라이브러리 `trace`로 14개 단위 테스트를 실행했을 때 `cdtw.py`의
실행 가능한 545개 라인이 모두 실행되어 라인 커버리지 100%로 보고됐다.
이는 분기 조합 전체를 의미하는 branch coverage와는 다르므로, 본 보고서에서는
무작위·변환·오라클 검사를 별도로 병행했다.

## 11. 재현 방법

저장소 루트에서 실행한다.

```bash
python -m unittest discover -s tests -v
python validation/validation_suite.py
```

두 번째 명령은 고정 시드로 JSON 결과를 출력한다. 이번 실행의 원본 수치는
`validation/validation_results.json`에 보존되어 있다.

실데이터 실험은 별도이며 네트워크가 필요하다.

```bash
python experiments/sampling_rate_experiment.py
```

## 12. 최종 판정

현재 구현은 다음 수준에서는 신뢰할 수 있다고 판단한다.

- 1차원 호 길이 매개화 CDTW의 셀 내부 비용 계산
- 경계 표본 기반 동적계획 결과와 경로 복원
- 대칭성·평행이동·크기변환·동시 역순 등의 수학적 일관성
- 격자 세분에 따른 비증가 및 재표본화 차이 감소 경향
- 단일 평탄 구간에 바로 종료하지 않는 adaptive 안정화 판정
- 계산 전 보수적 메모리 차단
- 일반적인 중소 규모 실험의 기준 구현

다만 결과를 **정확한 연속 CDTW 값**이라고 표기하면 안 된다. 연구 보고서에서는
“셀 내부 최적화가 정확한 경계표본 수렴 근사”라고 명시하고, `grid_size`, 전체
세분화 이력, 최근 안정화 창의 최대 변화량을 함께 보고해야 한다.

기준 정의와 정확 알고리즘: Kevin Buchin, André Nusser, Sampson Wong,
*Computing Continuous Dynamic Time Warping of Time Series in Polynomial Time*,
SoCG 2022, DOI: 10.4230/LIPIcs.SoCG.2022.22.
